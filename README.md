# app.fae.academy

This app will be part of my Advanced Technician's Final Project in Web Application Development. App Fae Academy is a whimsical, cozy and productive videogame.

The theme is inspired from the book Fae Academy: The Pursuit of Cheng (Fae Academy: La Búsqueda de Cheng in it's original language) by Paola Fucheng. It's also inspired from Stardew Valley, Animal Crossing, Fae Farm and Spirit City: Lofi Sessions when it comes as a videogame. To be a web application I got inspired in Lofi Town and Club Penguin. And at least, as a productive app is inspired in Forest and To Do List MinimaList.

To consolidate the previous paragraph, the map and the characters users can create, are inspired in the book. And all the apps mentioned will help create the dynamics and controls, furthermore in the productivity part there will be a minimalist Pomodoro or Timer and a To Do List.

As an artist, I need to hightlight that AI will not be used for the art creation, such as: map, characters, music, et cetera. As a programmer, I find imposible not to use AI, but I'll reduce the usage and search in Internet, webs or forums, or not use it at all, this will be finally said when the videogame will be published.

### App features
- Pomodoro or Timer
- Minimalist To-Do List
- Lo-Fi and whimsical music
- Customization of character and their pet
- Map
  - Main building of Fae Academy
    - Library
    - Classes
    - Big dining room
  - 4 Houses
  - Unicorn stable
  - Dalia Café
  - The Tree of Souls

### Development requirements
- Relational or non-relational database
- Backend
- Hosting
- Creation and/or use of an API
- Use of frameworks
- Responsive frontend
- Login
- Rols (user, admin)
- Version control in a remote repository
- Testing

### Tools
- **Github:** for remote control version
- **Aseprite:** for the pixelart design
- **Beepbox:** for creating the music
- **Godot:** for creating the videogame

- Why Godot? It suits perfectly for a 2D videogame, it an intuitive and open source game engine.
